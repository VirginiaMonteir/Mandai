# Coordenação dos Agentes - Release 0.1.0

Este documento coordena as atividades dos 4 agentes do time para a release inicial do Mandaí.

## Visão Geral da Release

Release inicial focada em navegação básica de restaurantes, incluindo:
- Exploração de restaurantes por categoria
- Visualização de detalhes de restaurantes
- Busca por restaurantes
- Interface responsiva

## Agentes e suas Tarefas

### 1. Product Owner
**Documento de tarefa:** [/docs/agent-tasks/product-owner-task.md](./agent-tasks/product-owner-task.md)

Responsável por definir e priorizar as User Stories essenciais para esta release:
- Exploração de restaurantes
- Visualização de detalhes
- Busca e filtragem

### 2. Architect
**Documento de tarefa:** [/docs/agent-tasks/architect-task.md](./agent-tasks/architect-task.md)

Responsável por definir as decisões técnicas e arquiteturais fundamentais:
- Estrutura do projeto
- Arquitetura de componentes
- Estratégias técnicas

### 3. Backend Developer
**Documento de tarefa:** [/docs/agent-tasks/backend-developer-task.md](./agent-tasks/backend-developer-task.md)

Responsável por implementar a API necessária para suportar as funcionalidades:
- Endpoints para restaurantes
- Estrutura de serviços
- Dados mockados

### 4. Frontend Developer
**Documento de tarefa:** [/docs/agent-tasks/frontend-developer-task.md](./agent-tasks/frontend-developer-task.md)

Responsável por implementar as interfaces do usuário:
- Páginas principais
- Componentes reutilizáveis
- Integração com API

## Cronograma

Todas as tarefas devem ser concluídas até a próxima sincronização do time, quando será feito o primeiro release report.

## Coordenação

O Lead Agent irá:
1. Monitorar o progresso de cada agente
2. Facilitar comunicação entre os agentes quando necessário
3. Consolidar relatórios individuais no release report final
4. Identificar e resolver bloqueios
