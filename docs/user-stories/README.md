# User Stories - Mandaí

Este diretório contém todas as User Stories do projeto Mandaí, numeradas sequencialmente e organizadas por funcionalidade.

## Template Padrão

Todas as User Stories seguem o seguinte template:

```
#US-XX: Título da User Story

**Como** [tipo de usuário],
**eu quero** [ação],
**para que** [benefício].

## Critérios de aceite

- [] Critério 1
- [] Critério 2
- [] ...

## Notas técnicas

- Nota técnica 1
- Nota técnica 2
- ...

## Fora de escopo

- Item fora de escopo 1
- Item fora de escopo 2
- ...
```
